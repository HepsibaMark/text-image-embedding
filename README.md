# Text-to-Image and Image-to-Text using Embeddings and Patch Processing

An AI-based project that explores bidirectional image and text generation using text embeddings, image embeddings, and patch-based image processing.

## Project Overview

This project aims to implement two AI pipelines:

### Text-to-Image
Convert a natural language prompt into a generated image using text embeddings and a diffusion-based image generation model.

### Image-to-Text
Analyze an input image using image patches and embeddings to generate a textual description.
